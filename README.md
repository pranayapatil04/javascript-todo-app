JavaScript To-Do List Application
Overview

A fully functional To-Do List application built using HTML, CSS, and JavaScript. The project demonstrates DOM manipulation, event handling, local storage persistence, filtering, and state management.

Features
Add new tasks
Edit existing tasks
Delete tasks
Mark tasks as completed
Filter tasks (All, Active, Completed)
Task counter
Enter key support
Local Storage persistence
Event Delegation
Dynamic DOM rendering
Technologies Used
HTML5
CSS3
JavaScript (ES6)
